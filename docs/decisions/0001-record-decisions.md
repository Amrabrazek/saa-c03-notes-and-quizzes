# 0001. Record architecture decisions

_Date: 2026-10-24 · Status: accepted_

## Context
Decisions get lost in chat history, and each Claude session starts without them.

## Decision
One markdown file per non-obvious decision in `docs/decisions/`, numbered.

## Why
Cheap to write, lives next to the code, and Claude can read it.

## Consequences
Write one whenever you'd otherwise explain the same choice twice.
